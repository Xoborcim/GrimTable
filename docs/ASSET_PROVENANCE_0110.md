# 0.11.0 asset provenance

The new arch, buttress, fractured-wall, pillar, factory, generator, refinery,
communications-spire, pipe, bunker, gantry, barricade, wreck, crater, rubble and
runoff geometry is generated by `scripts/terrain/monumental_terrain.gd`.
Its shared 12-material library and procedural weathering are original MIT work.
Dice are original chamfered meshes with modeled pips, original tray geometry,
and a short synthesized impact sound. No external sound recording was used.
Default authored miniatures remain available; their material and base shading
were improved. No Games Workshop meshes, symbols, ripped models or BG3 assets
are included.

The new visual direction uses original procedural architecture rather than
waiting for additional downloads. No failed archive endpoint was retried.
These pages verify candidate licensing, not an inventory of newly included
files. The existing included inventory is `assets/third_party/assets.json`.

For manual installation, obtain a model from its creator, verify the license of
the actual downloaded files, convert to standard GLB if necessary, and use
Miniature Library ? Import Model. Existing documented mod visual installation
remains available for content authors. Merely importing locally grants no rights
to distribute it. Keep creator/source/license/notes in the library if useful;
private models are not silently packaged into mods or shared over multiplayer.
