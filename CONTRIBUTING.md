# Contributing to GrimTable

Use Godot 4.6.1 standard edition and typed GDScript. Preserve the existing
authoritative gameplay, save/replay and multiplayer action architecture.

Run focused checks for the affected system during development; the isolated
runner is `godot --headless --path . --script res://tools/run_checks.gd`.
Avoid repeatedly running the complete regression for small changes.

By submitting original contributions, you agree to license them under the
project's [MIT license](LICENSE). Keep third-party files under their existing
licenses and preserve their notices. Include source, creator, license and
checksums for imported assets. Do not submit proprietary game assets, unclear
license content, credentials, private keys or player saves.
